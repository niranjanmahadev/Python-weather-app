# Python-weather-app# 🌤️ Python Weather App

A simple command-line weather application built using Python. It fetches current weather information for a city and displays it in the terminal.

## ✨ Features

- 🔎 Search weather by city
- 🌡️ Temperature
- 💧 Humidity
- 💨 Wind speed
- ☁️ Weather condition
- ⚠️ Basic error handling

## 🛠️ Technologies Used

- Python
- Requests
- wttr.in weather service

## 📦 Installation

Install the required Python package:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the application:

```bash
python weather.py
```

Enter a city name when prompted.
